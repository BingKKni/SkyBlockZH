# SkyBlockZH

一个翻译 Hypixel SkyBlock 玩法内文本为中文语言的 Mod。

**这个 Mod 的核心目的:** Hypixel 的 SkyBlock 玩法目前没有本土化翻译的计划，故游戏内所有的文本都是英文语言。通常玩家在截图游戏内容分享给自己的中文母语朋友时，大部分朋友由于没有玩过这个游戏，又看全是英文，就会产生一种"不想看"，"不想了解"的心理。本 Mod 就是重点解决这个问题的，而且要让 SkyBlock 里面的文本尽可能的翻译然后展现给中文玩家，让中文新手玩家能够更快地上手游戏（虽然 Hypixel 里面用到的英文词汇不难，但母语者肯定更偏向看到自己熟悉的语言，而不是花大量时间去理解英文词汇和句子），让中文玩家之间的交流不再有障碍。

**局限性:** SkyBlock 玩法非常庞大，且每一次的游戏更新都可能会更改游戏内的文本，造成部分本地已翻译的文本失效。由于本项目为非官方翻译项目，部分词汇和句子翻译出来的成果可能会和老玩家之间自己的翻译有出入，本项目不是为了统一玩家之间的译文去制作的，也不是为了给那些 *固执* 的老玩家制作的，是给新玩家和没玩过游戏的，希望在 SkyBlock 里面阅读翻译后的中文文本的玩家制作的。

**Mod 的特点:**

1. 不干扰其他辅助 Mod 运行。这说明你仍然可以使用 SkyBlocker、SkyHanni 等辅助 Mod；
2. 翻译支持随时开关。如果你安装了 ModMenu Mod，你就可以在 Mod 设置内随时开关翻译功能，以对比其翻译后的效果如何。没有安装也可以通过修改 config 文件重启游戏来开关功能；
3. 支持开关翻译原文对比。开启对比后，译名后面将额外加一串原文，如: "收藏品（Collections）"，防止物品名被翻译后玩家无法再在集市或拍卖行里搜到对应的物品；
4. 少机翻。虽然该 Mod 和翻译文本为 AI 生成，但开发者（我）对其生成翻译和引擎的质量是有严格标准的，并非随意一句需求生成完 Mod 和翻译就丢到 GitHub 上了。本 Mod 在由 AI 实现时至少吃掉了 1B 的 Token，成本极高，且每次新增/改动完代码和翻译后开发者（我）都会放到本地实测效果，确保 AI 不会改出 Bug 来；
5. 不该翻的不翻。如 NPC 人名、专有名词（Mining 的 Amber、Topaz 宝石等）等不适合被翻译的词条文案；
6. 不连接到任何翻译 API；

**局限性:**

颜色、居中、跨行语序这几件事，引擎侧都已经有对应机制（怎么做的见开发者文档）。下面列的是**残留个案**——机制在，但某几条文本还没按机制写好，或者那个位置本身就有精度上限：

1. 颜色失真。SkyBlock 一行文本经常中途换好几次色，引擎按语料里的颜色分段、渲染时从屏幕上读每段的真实颜色。还没切好分段的那些记录，整行会被刷成第一段的颜色；

2. 翻译语序不正确。分段之间可以调换渲染顺序，但英文被排版拆成多行、而中文的断句位置和它对不上时，仍然会读起来别扭（多数发生于多行文本）；

3. 翻译机翻味严重或该文案有更好的翻译。这是逐条译文的质量问题，发现一条改一条；

4. 翻译后的文本居中效果和原文有差异。容器标题、BossBar、动作栏、标题副标题这几处 Mod 自己决定绘制坐标，按译文真实像素宽重算；聊天里的居中横幅只能靠空格填充，一个空格 4px，所以会有几个像素的误差；

5. 部分名词被翻译，而在其他地方却看到该名词的原文（常见于地名，这个是因为其他部分玩法还未开始翻译工作导致显示出了原文）；
