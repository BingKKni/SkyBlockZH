# SkyBlockZH

一个由 [QQ幻梦Bot开发者](https://xbdqwq.com/) 制作的翻译 Hypixel SkyBlock 玩法内文本为中文语言的 Mod。

## 为什么制作这个 Mod？
Hypixel 的 SkyBlock 玩法目前没有本土化翻译的计划，故游戏内所有的文本都是英文语言。通常玩家在截图游戏内容分享给自己的中文母语朋友时，大部分朋友由于没有玩过这个游戏，又看全是英文，就会产生一种"不想看"，"不想了解"的心理。本 Mod 就是重点解决这个问题的，而且要让 SkyBlock 里面的文本尽可能的翻译然后展现给中文玩家，让中文新手玩家能够更快地上手游戏（虽然 Hypixel 里面用到的英文词汇不难，但母语者肯定更偏向看到自己熟悉的语言，而不是花大量时间去理解英文词汇和句子），让中文玩家之间的交流不再有障碍。

## 这个 Mod 的局限性？
SkyBlock 玩法非常庞大，且每一次的游戏更新都可能会更改游戏内的文本，造成部分本地已翻译的文本失效。由于本项目为非官方翻译项目，部分词汇和句子翻译出来的成果可能会和老玩家之间自己的翻译有出入，本项目不是为了统一玩家之间的译文去制作的，也不是为了给那些 *固执* 的老玩家制作的，是给新玩家和没玩过游戏的，希望在 SkyBlock 里面阅读翻译后的中文文本的玩家制作的。

## Mod 的特点是？

1. **不干扰其他辅助 Mod 运行** 这说明你仍然可以使用 SkyBlocker、SkyHanni 等辅助 Mod；
2. **翻译支持随时开关** 输入 `/skyzh` 或在 ModMenu 中打开设置页（分类与搜索方式同 SkyHanni 的设置界面），可随时开关翻译功能，也可以单独关闭 SkyBlock 玩法名、物品名、生物名的翻译，以对比其翻译后的效果如何。没有安装 ModMenu 也可以通过修改 config 文件重启游戏来开关功能；
3. **按热键切换原文（默认 X 键）** 按一次显示原文，再按一次恢复译文。可先切换再打开聊天栏查看历史对话，也方便在集市或拍卖行搜索物品。聊天输入时不会把字母 X 当作快捷键；切换世界后仍保留原文模式；关闭 Mod 或解绑热键后清除临时状态，不修改总开关。
4. **少机翻** 虽然翻译文本大部分为 AI 生成，但我们对其生成翻译和引擎的质量是有严格标准的，并非随意一句需求生成完 Mod 和翻译就丢到 GitHub 上了。本 Mod 在由 AI 实现时至少吃掉了 1B 的 Token，成本极高，且每次新增/改动完代码和翻译后开发者（我）都会放到本地实测效果，确保 AI 不会改出 Bug 来。本 Mod 引擎和框架使用 GPT 6 Astra 和 Claude Fable 5.1 共同构建，翻译部分用中等级模型+人工完成；
5. **不该翻的不翻** 如 NPC 人名、专有名词（Mining 的 Amber、Topaz 宝石等）等不适合被翻译的词条文案；
6. **翻译离线运行，支持自动更新** 翻译本身不连接任何翻译 API。开启“检查更新”后，进入空岛生存时会通过 GitHub 检查 Mod 与翻译更新；翻译更新立即生效，Mod 更新在退出游戏后安装，下次启动生效。不会上传玩家或游戏数据；
7. **只在 Hypixel 工作** 非 Hypixel 服务器不会开启 Mod 的翻译；
8. **文本间距可调** 默认按 Minecraft 1.12.2 的非全角方式渲染中文（逗号、句号更紧凑），可在设置页「高级」中改回原版全角。

## 关于技术的局限性

颜色、居中、跨行语序这几件事，引擎侧都已经有对应机制（怎么做的见技术文档）。下面列的是**残留个案**——机制在，但某几条文本还没按机制写好，或者该问题本身就有技术上限：

1. 颜色失真。SkyBlock 一行文本经常中途换好几次色，引擎按语料里的颜色分段、渲染时从屏幕上读每段的真实颜色。还没切好分段的那些记录，整行会被刷成第一段的颜色；

2. 翻译语序不正确。行内分段、以及物品 Lore 中首行 + continuation 尾行的跨行分段，都可以调换渲染顺序；残留问题通常是某条语料还没补好分段/order；

3. 翻译机翻味严重或该文案有更好的翻译。这是逐条译文的质量问题，发现一条改一条；

4. 翻译后的文本居中效果和原文有差异。容器标题、BossBar、动作栏、标题副标题这几处 Mod 自己决定绘制坐标，按译文真实像素宽重算；聊天里的居中横幅只能靠空格填充，一个空格 4px，所以会有几个像素的误差；

5. 部分名词被翻译，而在其他地方却看到该名词的原文（这个是因为部分玩法还未开始翻译工作）；

## 支持哪些 Minecraft 版本？

目前我们只支持 Fabric 模组加载器，支持 Minecraft 26.1.x、26.2 和 26.3。

| 你的 Minecraft | 下载 |
| :---: | :---: |
| 26.1、26.1.1、26.1.2 | `SkyBlockZH-<版本>-Beta-Fabric-26.1.jar` |
| 26.2 | `SkyBlockZH-<版本>-Beta-Fabric-26.2.jar` |
| 26.3 | `SkyBlockZH-<版本>-Beta-Fabric-26.3.jar` |

文件名末尾的 `Beta-Fabric-26.1` / `Beta-Fabric-26.2` / `Beta-Fabric-26.3` 表示 Fabric 加载器及对应的 Minecraft 版本。

## 翻译包与自动更新

自动更新默认开启，可在设置页或用 `/skyzh updatecheck on/off` 开关。设置页的「检查更新」可选关闭、正式版或测试版（测试版为每次提交自动构建的 Mod）；「安装更新方式」可选自动下载并安装、自动下载但手动决定是否安装（聊天栏点击 `[点击安装]`）或仅检查（点击 `[点击下载并安装]`），后两种每次检查都会再次提醒，有更新的版本时自动替换已下载的包。`/skyzh updatecheck` 主动依次检查 Mod 和翻译包；加 `mod` 或 `translate` 仅检查对应更新，发现更新后自动下载安装。主动检查不受自动更新开关或等待时间限制，也不会修改开关；检查和安装期间重复请求会报错。`/skyblockzh` 同样支持。需开启 Mod 总开关并进入 Hypixel 空岛生存后才检查，主界面、大厅和其他服务器不会检查。一般每小时检查一次；网络或下载失败一小时后重试，新翻译不兼容当前 Mod 时七天后重试，重启会保留等待时间。错误提示中的按钮可立即重试，仍会校验文件并防止重复下载。手动包覆盖新翻译时，可点击提示中的卸载按钮永久删除该手动包，随后立即重载；删除范围仅限 `skyzh-translations/translations.zip`。

手动安装的 `skyzh-translations/translations.zip` 始终优先。没有可用手动包时，自动下载的 `skyzh-updates/translations.zip` 只有在 API 兼容、生成时间比内置包新且内容不同时才优先，否则使用 Mod 自带翻译。内置翻译成功加载后会清理已被替代的自动包；清理失败也不会让旧包影响更新检查。选中的来源无法使用时尝试其他可用来源。下载的翻译包通过完整校验后才安装。

Mod 新版本下载到 `skyzh-updates/`，退出游戏后由独立安装程序替换原 JAR，并将旧文件备份到该目录。看到下载成功提示后，退出并重新启动游戏即可使用新版本。若启动器阻止辅助程序运行或目录不可写，Mod 会保留当前版本并提示稍后重试。

项目每次推送都会运行 Actions，翻译、API 或打包输入发生变化时自动打包；也可在 Actions 页面手动运行 `Publish translation updates` 强制发布。翻译 ZIP 使用最高等级的 DEFLATE 压缩，通过 [GitHub Pages](https://bingkkni.github.io/SkyBlockZH/) 托管，不写入 Git 历史，也不创建翻译 Release；仓库只保存 `skyzh-updates/update.json`。部署成功且下载校验通过后才更新清单，并保留前两版文件供正在更新的客户端继续下载。正式 Mod 更新仍通过正式 Release 发布，并提供对应 Minecraft 的 JAR 附件。
